# Product brief

**Задача.** Переводить длинные документы локально, сохранять оригиналы, состояние и отдельные результаты. Проект выбирает исходный язык явно или поручает распознавание модели; один исходник можно переводить на несколько целевых языков.

В интерфейсе доступны коды языков из списка конкретной модели. Для Hy-MT2 это таблица карточки, для TranslateGemma - пересечение карты шаблона и списка языков приложения. Это не обещание качества каждой пары. Qwen3 в каталог по умолчанию не входит: его GGUF можно взять с рынка. Модель без закреплённого файла GGUF не скачивается. Скачанный GGUF можно выбрать для проекта; runtime, который на Windows не проверялся, может не запуститься.

**Первый пользовательский маршрут.** Приложение автоматически определяет ресурсы устройства и предлагает модель по расчётной памяти и свободному месту → создать проект → добавить документы → просмотреть ограничения импорта/экспорта → подтвердить загрузку модели → подтвердить запуск → следить за очередью без выдуманного ETA → проверить текст рядом с источником → исправить → экспортировать отдельный файл.

## MVP поведение

- Проект хранит языки, модель, контекст, правила, глоссарий, документы, события задач, переводы и экспортную историю.
- Импорт копирует оригинал в проект и сохраняет SHA-256. Inference и экспорт работают с отдельными производными. Проверка хеша останавливает экспорт, если копию источника изменили за пределами приложения.
- Сегментация ограничивает вход короткими порциями и сохраняет исходную пунктуацию и пробелы. Для prompt используются проектные правила, глоссарий и два последних завершённых фрагмента. Книга не отправляется одним запросом.
- Данные сегментов коммитятся отдельно. После сбоя остаются завершённые фрагменты; незаконченный можно продолжить или повторить. Ошибка runtime не помечается как успешный перевод.
- История экспорта записывается в проект; начальная папка экспорта — `project/output`. Пользователь может выбрать другое место.
- Первый запуск измеряет RAM, свободное место, GPU и сведения о сборке backend. Неизвестные значения остаются неизвестными. Подбор предлагает наибольшую модель каталога по всей RAM устройства с запасом 1 ГБ и наличию места; свободная RAM вердикт не меняет. Это не рейтинг качества. CPU-потоки настраиваются автоматически. GPU-слои включаются, только если свободной VRAM хватает на расчёт модели; иначе перевод идёт на CPU.
- Модельные веса загружаются только после выбора карточки, ознакомления с лицензией, отметки согласия и отдельного подтверждения файла и размера.
- Пользователь может импортировать локальный GGUF после отдельного подтверждения. Приложение копирует его в каталог моделей, проверяет размер и SHA-256; исходник не меняется. Языки и контекст задаются пользователем, поддержка chat template проверяется при запуске.

## Вне текущего выпуска

- Нет доказанного качества перевода: одинакового ручного benchmark EN↔RU и реальной локальной модели в тестовой среде нет.
- Не подтверждены запуск llama-cpp-python на Windows, GPU offload, расход ресурсов, производительность, размер готового дистрибутива и установщик.
- Скан PDF читается Windows OCR и возвращается картинкой страницы. Качество распознавания не измерено. Tesseract не входит. Автообновления, staged swap/rollback и подписанного релиза нет.
- Нет импорта HTML, RTF, ODT, PPTX или XLSX. Архитектура для этих адаптеров есть, заявленной поддержки пока нет.
- Не реализованы синхронизация проектов между устройствами, совместное редактирование и удалённые сервисы.

## Показатели успеха для следующего релиза

1. На чистой Windows 10/11 x64 пользователь устанавливает подписанный Setup.exe без Git/Python и запускает app.
2. Установка модели показывает свободное место, точный размер, лицензия, pinned ревизию и реальное согласие; скачивание можно возобновить.
3. Пример English ↔ Russian переводится на одной модели/квантовании при сохранённом хеше оригинала; тестовый набор и ручная рубрика публикуются вместе с метриками RAM/VRAM/скорости.
4. Закрытие во время задания восстанавливает его, а очередь несколько документов не повреждает результаты.
5. Удаление приложения сохраняет пользовательские проекты и модели; автообновление проходит staged swap, контроль и rollback.
