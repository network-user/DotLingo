# Сборка и проверка Windows

Первая целевая система: Windows 10/11 x64, CPython 3.12. Пользователю нужен только `Setup.exe`; Git и Python входят в приложение через PyInstaller onedir. Сборка требует сеть для Python packages и inference runtime. GGUF-веса не входят в установщик. Распознавание сканов использует языки OCR, уже установленные в Windows.

## Сборка

1. Установить Python 3.12 x64 на машине сборки. Если `ISCC.exe` нет, `build.ps1` скачивает Inno Setup 6.7.3 в `build\tools`, сверяет SHA-256 и ставит компилятор туда же.
2. В PowerShell из корня checkout выполнить `deploy\windows\build.ps1`.
3. Скрипт создаёт новый каталог `build\windows\<timestamp>`, отдельный venv, ставит `.[pdf,build]`, затем через `run_install('cpu')` скачивает закреплённое CPU-колесо `llama-cpp-python==0.3.35`, сверяет SHA-256 и только после этого вызывает pip. Дальше собирает onedir через `deploy\windows\DotLingo.spec` и `Setup.exe` через ISCC. Скрипт не чистит существующие build каталоги.
4. Артефакт ожидается в `build\windows\<timestamp>\installer\DotLingo-0.1.0-Setup.exe`.

Нет измерения размера дистрибутива: он включает CPython, web-ресурсы `dotlingo/web`, рантайм pywebview (`webview`, `pythonnet`, `clr_loader` через `collect_all` в spec), `llama-cpp-python` и нативные llama.cpp DLL, python-docx, pypdf и приложение; `tkinter` исключён из бандла. Поэтому размер Setup нельзя честно назвать до успешной сборки. Inno Setup использует LZMA2; PyInstaller onedir выбран для прямого запуска нативных DLL и диагностики вместо однофайловой распаковки. Новые/неподписанные бинарники могут вызывать SmartScreen или эвристики антивируса; перед публикацией нужно проверять все файлы, подписывать Setup и EXE сертификатом организации и публиковать хеши. Подпись не гарантирует отсутствие предупреждений.

Установщик (`installer.iss`) проверяет после установки наличие WebView2 Evergreen по ключу реестра `EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}` (HKCU и HKLM WOW6432Node). Если runtime не найден, показывается MsgBox с подсказкой и ссылкой на установщик Microsoft. Установщик не скачивает WebView2 сам.

## Пути и удаление

- Приложение устанавливается per-user в `%LOCALAPPDATA%\Programs\DotLingo`.
- Проекты, SQLite, результаты, настройки и модели хранятся отдельно в `%LOCALAPPDATA%\DotLingo`.
- Inno Setup регистрирует uninstall, ярлык меню «Пуск» и необязательный ярлык рабочего стола.
- В `[UninstallDelete]` нет удаления пользовательских данных. Текущий uninstall script удаляет только каталог приложения и shortcuts.
- Дополнительные модели не входят в установщик. Распознавание сканов берёт языки Windows, а не отдельный пакет Tesseract. Первый запуск позволяет отложить выбор и загрузку модели.

## Ручная приёмка на чистой Windows VM

После сборки, отдельно от машины разработчика:

1. Установить Setup обычным пользователем и проверить запуск без Python/Git, меню «Пуск» и необязательный desktop shortcut. Если WebView2 отсутствует, убедиться, что установщик показал подсказку с ссылкой.
2. В мастере проверить неизвестную/известную hardware-информацию, отмену загрузки, нехватку диска, прерывание сети, повторную загрузку, лицензионное согласие и отложенную установку.
3. Проверить тему-переключатель (светлая/тёмная) и сохранение выбранной темы между запусками.
4. Отключить сеть и пройти TXT → локальная модель → review → TXT export. Проверить сохранение исходника и повторный запуск проекта.
5. Проверить импорт/экспорт DOCX и EPUB, текстовый PDF, скан PDF с переводом поверх страницы, UI при окне малого размера и Windows scaling.
6. Проверить обновление новой версией Setup поверх предыдущей установки и убедиться, что проекты, выгрузки и веса сохранились; проверить uninstall и повторный запуск существующего проекта.

Эти шаги пока не исполнены: в текущей среде отсутствуют PyInstaller и Inno Setup. Клон исходников сверяется с `origin/main` при запуске и обновляется кнопкой в «Настройках» или скриптом `deploy\update.ps1`: fetch, `reset --hard` и `pip install -e ".[pdf]"`. Данные в `%LOCALAPPDATA%\DotLingo` при этом не трогаются. Установленный Setup.exe так не обновляется: для него нужен новый Setup. Подписанного manifest, staged swap и rollback у установщика нет.

Сборка CPU-only. Поддержка GPU намеренно не включена: для неё нужен отдельный backend build, его DLL и отдельное испытание модели/квантования/context на каждой целевой комбинации Windows и GPU.
