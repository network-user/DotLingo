# Сборка и проверка Windows

Первая целевая система: Windows 10/11 x64, CPython 3.12. Пользователю нужен только `Setup.exe`; Git и Python входят в приложение через PyInstaller onedir. Сборка требует сеть для Python packages и inference runtime. GGUF-веса и OCR не входят в установщик.

## Сборка

1. Установить Python 3.12 x64 и Inno Setup 6 на машине сборки.
2. В PowerShell из корня checkout выполнить `deploy\windows\build.ps1`.
3. Скрипт создаёт новый каталог `build\windows\<timestamp>`, отдельный venv, ставит `.[inference,pdf,build]` и CPU wheel `llama-cpp-python==0.3.35`, собирает onedir через `deploy\windows\DotLingo.spec`, затем создаёт `Setup.exe` через ISCC. Скрипт не чистит существующие build каталоги.
4. Артефакт ожидается в `build\windows\<timestamp>\installer\DotLingo-0.1.0-Setup.exe`.

Нет измерения размера дистрибутива: он включает CPython/Tcl-Tk, `llama-cpp-python` и нативные llama.cpp DLL, python-docx, pypdf и приложение. Поэтому размер Setup нельзя честно назвать до успешной сборки. Inno Setup использует LZMA2; PyInstaller onedir выбран для прямого запуска нативных DLL и диагностики вместо однофайловой распаковки. Новые/неподписанные бинарники могут вызывать SmartScreen или эвристики антивируса; перед публикацией нужно проверять все файлы, подписывать Setup и EXE сертификатом организации и публиковать хеши. Подпись не гарантирует отсутствие предупреждений.

## Пути и удаление

- Приложение устанавливается per-user в `%LOCALAPPDATA%\Programs\DotLingo`.
- Проекты, SQLite, результаты, настройки и модели хранятся отдельно в `%LOCALAPPDATA%\DotLingo`.
- Inno Setup регистрирует uninstall, ярлык меню «Пуск» и необязательный ярлык рабочего стола.
- В `[UninstallDelete]` нет удаления пользовательских данных. Текущий uninstall script удаляет только каталог приложения и shortcuts.
- OCR и дополнительные модели не входят в установщик. Первый запуск позволяет отложить выбор и загрузку модели.

## Ручная приёмка на чистой Windows VM

После сборки, отдельно от машины разработчика:

1. Установить Setup обычным пользователем и проверить запуск без Python/Git, меню «Пуск» и необязательный desktop shortcut.
2. В мастере проверить неизвестную/известную hardware-информацию, отмену загрузки, нехватку диска, прерывание сети, повторную загрузку, лицензионное согласие и отложенную установку.
3. Отключить сеть и пройти TXT → локальная модель → review → TXT export. Проверить сохранение исходника и повторный запуск проекта.
4. Проверить импорт/экспорт DOCX и EPUB, текстовый PDF, отказ для PDF scan, UI при окне малого размера и Windows scaling.
5. Проверить обновление новой версией Setup поверх предыдущей установки и убедиться, что проекты, выгрузки и веса сохранились; проверить uninstall и повторный запуск существующего проекта.

Эти шаги пока не исполнены: в текущей среде отсутствуют PyInstaller, Inno Setup и рабочий Tcl/Tk. Релизный автоматический update с подписанным manifest, staged swap и rollback пока не реализован. До появления URL обновлений, формата подписанного manifest и ключа издателя установленные версии нужно обновлять новым подписанным Setup; проверка update/rollback остаётся задачей перед релизом.

Сборка CPU-only. Поддержка GPU намеренно не включена: для неё нужен отдельный backend build, его DLL и отдельное испытание модели/квантования/context на каждой целевой комбинации Windows и GPU.
