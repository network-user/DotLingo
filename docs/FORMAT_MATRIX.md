# Матрица форматов

Значок «тесты» означает локальные тесты фикстур, а не проверку каждого варианта стандарта. Импорт парсера не гарантирует качественный обратный экспорт.

| Формат | Импорт | Экспорт | Что сохраняется | Ограничения | Зависимости | Проверки |
|---|---|---|---|---|---|---|
| TXT | Да, UTF-8/UTF-8 BOM и CP1251 | TXT | Порядок абзацев и точные разделители строк/пробелов | Неизвестная кодировка отклоняется; нет метаданных/стилей | Стандартная библиотека | Round-trip CRLF/пробелов и CP1251 |
| Markdown | Да, `.md`/`.markdown` | `.md` или `.txt` | Заголовочные уровни, маркеры списков/цитат, fenced code, пустые блоки | Inline Markdown остаётся частью текста модели; переносы строк внутри прозы могут измениться; HTML/raw blocks не разбираются полностью | Стандартная библиотека | Заголовки/кодовая ограда; fixture |
| DOCX | Да | DOCX, TXT, Markdown | Параграфы, заголовки, таблицы и их контейнеры; при DOCX-экспорте остаются стили исходного документа | Runs внутри абзаца сливаются в первый текстовый run; inline-жирность/курсив и другие отличающиеся участки могут потеряться. Header/footer, текстовые поля, сноски и изображения не входят в дерево | `python-docx`, `lxml` | Документ с таблицей: импорт → изменённый DOCX → исходник хеширован |
| EPUB | Да | EPUB, TXT, Markdown | Порядок spine, XHTML-файлы, архивные ресурсы и ссылки вне переведённых text nodes | Inline spans flatten до простого текста; сложная вложенная разметка может упроститься; CSS/скрипты/изображения не переводятся | `zipfile`, XML из stdlib | Книга с двумя главами, text nodes и непереводимым SVG asset |
| PDF с текстовым слоем | Да. Пустой пароль пользователя снимается, пароль на открытие отклоняется | Книга со шрифтом полосы ModernMT: тот же PDF. Иначе новый PDF с текстом, а также TXT или Markdown | У книжной укладки: иллюстрации, полоса и номера страниц. Абзац, который не входит в строку, дописывается в конец того же PDF. Иначе текст и границы страниц | Укладка не обещает произвольный офисный PDF. Страница с очень малым текстом на обычном PDF останавливает импорт как возможный скан | `pypdf`, для укладки ещё `pdfminer.six`, `reportlab`, `pypdfium2` | Текстовый PDF без полосы собирается новым PDF. Книжная полоса, слишком длинный абзац и пустой пароль: отдельные тесты |
| PDF-скан или смешанный PDF | Нет, если найдена страница без достаточного текстового слоя | Нет | Ничего до отдельного OCR-подтверждения | OCR не запускается молча. Для первой версии нужен отдельный opt-in шаг с отображением страниц/языков | OCR не входит | Пустой/сканоподобный PDF: честная ошибка с номерами страниц |

## OCR-путь для следующей версии

Подход для будущего OCR: использовать отдельный PDF renderer для image-only страниц и отдельный Tesseract executable с `eng`/`rus` traineddata; не включать OCR по умолчанию. Нынешняя permissive PDF-библиотека не растеризует страницы. Документация Tesseract говорит, что нового официального Windows installer у проекта нет; распространённые Windows installer являются сторонними. Перед реализацией нужно выбрать и проверять источник renderer и Windows binary, pin/хеш бинарников и данных, включить лицензии Tesseract/Leptonica и renderer, измерить дополнительный размер и прогнать сканы с ручной рубрикой. [Tesseract: установка и языковые данные](https://tesseract-ocr.github.io/tessdoc/Installation.html), [Windows downloads](https://tesseract-ocr.github.io/tessdoc/Downloads.html), [лицензия и зависимости](https://github.com/tesseract-ocr/tesseract).

Пока OCR недоступен. PDF использует только текстовый слой; импорт не обещает восстановление сложного чтения колонок и порядка элементов. `pypdf` выбран вместо PyMuPDF: последний распространяется под AGPL-3.0 или коммерческой лицензией Artifex, что добавило бы лицензионные условия к standalone-сборке. [pypdf license](https://pypdf.readthedocs.io/en/latest/meta/faq.html), [PyMuPDF licensing](https://pymupdf.readthedocs.io/en/latest/about.html).

## Новые адаптеры

Адаптер должен вернуть `ParsedDocument` с упорядоченными `Block`, section id/title и format locator; export writer должен получить исходный файл, нормализованное дерево и карту переводов, записать новый файл и пройти fixture round-trip. Новый формат сначала включается в матрицу с ограничениями и отдельными импорт/экспорт-тестами, затем становится доступен в UI.
