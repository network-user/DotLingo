## Что проверялось и не стало находкой

Секретов, приватных ключей и токенов в индексе и в истории нет. POST `/js_api` в установленном pywebview 5.4 не вызывает методы: словарь callback пуст. Навигация WebView пускает только `about:blank` и loopback текущего порта. Текст документа и ответ модели идут в `textContent`, событие в страницу собирается через `json.dumps`. ZIP не распаковывается на диск, у импорта есть потолок размера. Загрузка модели не активирует файл без размера, SHA-256 и заголовка GGUF. `git reset` при старте не выполняется. Обновление наследует окружение того же пользователя: это не граница с более слабым субъектом.

Заявки про symlink в каталоге данных отклонены по той же причине. Ссылку там создаёт сам пользователь ОС. Контроль суффикса и списка проектов всё равно выровнен, чтобы процесс не открывал и не мигрировал чужую цель такой ссылки.

Значения секретов в отчёт не включались.
