## Аппаратные профили

Это рекомендации, а не блокировка ручного выбора. На слабом CPU-only устройстве можно начать с Qwen3-1.7B Q8_0, если фактически доступной RAM хватает на модель, runtime, контекст и приложение; скорость остаётся неизвестной. На среднем компьютере Qwen3-4B Q4_K_M является сравнительным кандидатом с большим дисковым/RAM запасом, не обещанием качества. На GPU-системе текущий worker всё равно запускает CPU-only путь: аппаратная поддержка backend сама по себе не включает GPU и не подтверждает объём VRAM. До реального GPU adapter профиль GPU остаётся информационным.

Размер файла берётся из закреплённого артефакта. Загрузчик требует ещё 256 MiB временного запаса поверх оставшихся байтов. RAM/VRAM оценки приложения не измерены и не должны трактоваться как гарантия запуска. При неизвестном показателе UI показывает, что определить его не удалось.

При запуске DotLingo повторно определяет доступную RAM и свободное место. Автоматическая рекомендация выбирает наибольшую доступную модель, для которой хватает расчётной RAM с резервом 1 ГБ и диска. Это только оценка размещения; качество моделей не ранжируется. CPU inference использует автоматически рассчитанное число потоков (не более 8, с одним оставленным логическим потоком); GPU offload пока выключен. Вкладка моделей позволяет добавить локальный GGUF: пользователь задаёт коды языков и контекст, а размер, GGUF magic и SHA-256 проверяются при импорте. Работу chat template нужно проверить запуском.
