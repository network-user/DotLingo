# Передача DotLingo

Снимок: 2026-10-02, ветка `main`. Снимок от 2026-09-26 описывал Tkinter и каталог Qwen3. С тех пор UI переведён на pywebview (ADR-008), каталог по умолчанию заменён на Hy-MT2 (ADR-009).

## Сейчас в приложении

- Окно pywebview и веб-слой `src/dotlingo/web/`. Мост `api.py`, push-события, темы через `[data-theme]`.
- Каталог загрузки: официальные GGUF Tencent Hy-MT2 1.8B Q4_K_M, 1.8B Q8_0 и 7B Q4_K_M. Ревизия, размер и SHA-256 закреплены в `models.json`. Веса в этой среде не скачивались.
- Промпт и сэмплинг Hy-MT2 берутся из карточки: одна user-реплика, только перевод, temperature 0.7, top_p 0.6, top_k 20, repetition penalty 1.05, контекст 8192. Правленые пары проекта подмешиваются короткой памятью.
- GPU-слои включаются по свободной VRAM. Если старт на GPU упирается в память, задача повторяет загрузку на CPU. Пользовательский GGUF без оценки VRAM остаётся на CPU.
- Проверка перевода различает пустой блок, машинный черновик и правку, показывает черновик модели и пропуски глоссария. Очередь после фрагмента показывает символы в секунду и устройство (CPU или GPU).

## Перед релизом

1. Поставить Inno Setup 6 и собрать Setup.exe по `docs/BUILD_WINDOWS.md` на Windows 10/11 x64. Проверить запуск без Python и подсказку, если нет WebView2.
2. После явного согласия скачать один закреплённый GGUF и прогнать EN↔RU по рубрике из `docs/MODEL_MATRIX.md`. Записать символы в секунду, RAM и то, ушли ли слои на GPU.
3. Подпись, издатель и обновление по-прежнему не сделаны. Setup не является автообновлятором.
