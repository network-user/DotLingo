# AGENTS.md

> Правила для coding agents. Пользовательский обзор находится в [README.md](README.md).

## Профиль проекта

- **Тип:** настольное приложение (ближайший профиль - CLI с локальным UI).
- **Аудитория:** internal.
- **Runtime:** CPython 3.12 или 3.13.
- **Платформа:** первая целевая система Windows 10/11 x64.
- **Монорепо:** нет.

## Быстрый старт

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev,pdf]"
python -m dotlingo
```

Для CPU inference см. [docs/LOCAL_SETUP.md](docs/LOCAL_SETUP.md). Модельные веса не устанавливаются автоматически.

## Сборка и проверки

| Действие | Команда |
|----------|---------|
| Установка разработки и PDF | `python -m pip install -e ".[dev,pdf]"` |
| Запуск приложения | `python -m dotlingo` |
| Тесты | `python -m pytest -q` |
| Lint | `python -m ruff check src tests` |
| Windows Setup.exe | `.\deploy\windows\build.ps1` |

Для сборки Setup.exe нужны CPython 3.12 x64, CPU wheel `llama-cpp-python` и Inno Setup 6. Сборка не проверена на чистой Windows VM.

## Структура репозитория

```text
src/dotlingo/       # UI, ядро, языки, форматы, модели и хранилище
tests/              # unit и smoke тесты
scripts/            # генерация иконки
deploy/windows/     # PyInstaller и Inno Setup
docs/               # продуктовые решения, матрицы и инструкции
pyproject.toml       # runtime, extras, pytest и Ruff
```

## Соглашения

- **Язык документации:** русский.
- **Интерфейс:** акцентный монохром. Цвета только из `src/dotlingo/web/styles/tokens.css`. Акцент - светлая кнопка на тёмном фоне и чёрная на светлом, без синих, фиолетовых и других брендовых цветов. Стекло, волосяные линии и приглушённые статусы (ошибка, успех, предупреждение) остаются семантическими и не заменяют акцент. Новые экраны не вводят свои hex-цвета.
- **Стиль Python:** Ruff, длина строки 100 символов, целевая версия Python 3.12.
- **UI:** pywebview (Edge WebView2) + веб-слой `src/dotlingo/web/` без сборки (vanilla JS ES-модули). Мост `api.py`: camelCase-методы, единый конверт `{ok, data}`, push-события через `evaluate_js`, долгие операции - в worker-потоках. Темы - CSS-переменные `[data-theme]`. Для запуска окна нужен WebView2; ES-модули раздаются через локальный HTTP-сервер pywebview, не `file://`.
- **Тесты:** pytest; тесты форматов, загрузчика модели, очереди, сегментации, моста и headless smoke (`python -m dotlingo --smoke-test`).
- **Импорт и экспорт:** поддержка чтения формата не означает поддержку качественной обратной записи; сверяй `docs/FORMAT_MATRIX.md`.
- **Изменения данных:** оригинал остаётся неизменяемым; переводы и экспорт хранятся отдельно.
- **Inference:** backend запускается отдельно от UI. Сохраняй отмену и обработку ошибок; не добавляй скрытые сетевые вызовы.
- **Переводы:** направление фиксируется в задаче. Переводы и экспорты разделяются по целевому языку; список языков ограничивается выбранной моделью.
- **Загрузка весов:** не загружай модели без явного согласия. Сохраняй закреплённые ревизии, размер, SHA-256 и атомарную активацию проверенного файла.
- **Рынок моделей:** шесть репозиториев Hugging Face в `market.py` (HY-MT1.5 1.8B/7B, Hy-MT2 1.8B/7B, Qwen3 4B/8B). Обновление только по кнопке, без скрытого запроса. На репозиторий до трёх GGUF, по роли скорость, баланс и точность. Скачивание после согласия, повторная сверка ревизии, размера и SHA-256. Поиск по всему Hub не включён. Качество перевода рынок не измеряет.
- **TranslateGemma:** в каталоге закреплённый GGUF Q4_K_M. Официальный Safetensors не скачивается. Промпт - текстовая форма шаблона Google: вшитый jinja не принимает обычную строку и ждёт `source_lang_code`, поэтому при запуске он заменяется метками `<start_of_turn>`. Системная роль пустая, стоп - `<end_of_turn>`. Контекст по умолчанию 2048.
- **Свои модели:** импортируй только выбранные пользователем локальные GGUF после отдельного подтверждения; копируй в каталог моделей и проверяй размер/SHA-256. Пользовательские языки и контекст не являются подтверждением совместимости или качества.
- **Автоподбор:** учитывай всю RAM устройства, не свободную, запас 1 ГБ и свободное место; рекомендация описывает только оценку размещения. GPU-слои включаются, только если свободной VRAM хватает на расчёт модели; иначе CPU. Потоки CPU настраиваются автоматически с пределом 8.
- **Каталог перевода:** четыре закреплённых GGUF в `src/dotlingo/models.json`: Hy-MT2 1.8B Q4_K_M, 1.8B Q8_0, 7B Q4_K_M и TranslateGemma 4B Q4_K_M. Не предлагай Qwen и STQ 1.25/2-bit как модели по умолчанию. Качество пар не заявляй без измерения.
- **Лицензии:** сверяй карточку модели и запись в `src/dotlingo/models.json`; не обещай поддержку модели только по её названию.
- **PDF:** текстовый слой через `pypdf`. Пустой пароль пользователя снимается при импорте; настоящий пароль на открытие по-прежнему отклоняется. Книга со шрифтом полосы ModernMT возвращается PDF: текст заменяется, иллюстрации и номера страниц остаются. Прочий PDF экспортируется в TXT или Markdown. OCR нет. PyMuPDF не используется из-за AGPL.

## Переменные окружения

В приложении нет обязательных переменных окружения. По умолчанию пользовательские данные Windows находятся в `%LOCALAPPDATA%\DotLingo`; тесты и разработка могут передавать `--data-dir`.

## Работа агента

- Перед правками читай затронутые файлы и соседний код.
- После изменений запускай релевантные проверки из таблицы выше.
- Не выдумывай команды, зависимости, версии, метрики или совместимость моделей.
- Не скачивай многогигабайтные веса без явного согласия пользователя.
- Не меняй `LICENSE` без явного запроса пользователя.
- Не коммить временные файлы и локальные данные.
- **README-sync:** глобальные изменения команд, модулей, зависимостей, архитектуры или runtime требуют обновить README и LoC через `generate-readme`, а правила - через `sync-project-rules`.
- Не латай README вручную; при запросе на изменение README перегенерируй его скиллом `generate-readme`.
- Минимизируй diff и не рефактори несвязанный код.
